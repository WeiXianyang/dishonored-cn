## 放行红线

- 模型不能直接写游戏文件；只由流水线原子写校对产物。
- `action=keep` 是默认，风格偏好不得改写天邈底色。
- 任一 `fix` 必须保留目标格式签名并遵守条目实际命中的正式术语。
- 修改率超过 35%、不确定率超过 10% 或连续两批失败时，停止全量运行并先校准。
- Phase 3 完成不代表修改已写回游戏；写回属于 Phase 5，并受 Phase 4 人工裁决约束。

Phase 3 已于 2026-08-06 完成并通过独立验收。人工审核占比为 `145 / 31,583 = 0.459%`，低于 5% 目标；最终接受修补率为 `6,398 / 31,583 = 20.26%`。详细证据见 `docs/phase3-final-report.md`，人工入口为 `data/review/phase3-final/human_review.html`。
